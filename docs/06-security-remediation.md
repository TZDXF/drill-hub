## 部署变化

- 局域网、公网和反向代理部署必须配置 `PUBLIC_URL`；不可再依赖任意请求 Host 生成外链。
- 浏览器跨域允许所有来源（含 `null`），无额外来源配置；Cookie 写操作仍需 CSRF。跨源读取会话与 CSRF 的风险保持开放，不能仅凭 CSRF 校验宣称已阻断报告中的攻击链。
- `TRUSTED_PROXIES` 默认空；只填写实际代理的 IP/CIDR，避免公开端口允许客户端伪造转发头。HTTPS 终结应设置 HTTPS 的公开地址。
- `ALLOW_PRIVATE_MODEL_URLS` 默认 `false`；开启后模型连接可以访问内网，应仅用于信任管理员且确有自建模型需求的部署，并配合出口网络限制。
- `ACCESS_LOG_RETENTION_DAYS` 默认 7，允许 1–365；只清理 API/登录运行日志，业务审计和评分历史永不由此清理。SQLite 删除记录后可复用页，不承诺数据库文件自动缩小。
- 上游 `comark@0.7.0` 的 KaTeX peer 范围仍声明 `^0.17.0`，所以包管理器会报告 peer 警告；未压制该警告或保留旧的不安全版本。公式渲染由现有真实浏览器测试验证。

## 后续建议与验证边界

本次不是生产安全认证。报告建议的 CSRF 短周期轮换、递增登录延迟、免登录链接列举/主动吊销接口、多实例数据库并发约束、CSP 深化、网关封禁、容量告警、管理权限细分及二次确认，仍需单独设计与验收。当前限流仍为单实例内存实现；Android APK/真机、真实模型质量与生产压力测试不在本次验证范围。
