# 01 · 系统、monorepo 与 Android 架构

基线：v0.2，2026-10-17。状态：实现前设计，不代表依赖已初始化。

## 1. 总体拓扑

```text
Web / 手机浏览器 ─┐
                  ├─ HTTP(S) ─ Node.js API ─ 业务服务 ─ TypeORM ─ SQLite
Tauri 2 Android ──┘               │              │
  填地址 → 验证 → 登录           │              └─ 持久评分任务 → 内部模型适配器 → 评分模型
外部云端 Agent ─ Bearer 令牌 ─────┘
  Skill：规划、创建题目/得分项、读取结果、请求重评、安排复习
```

- Web 前端和 API 生产部署建议同源；Android 打包前端资源后访问用户指定的服务器。
- 数据库、判分、计时、鉴权和模型调用都在服务端，Android 不运行 Node.js。
- 内部评分模型与完整 Pi Agent 独立；首版没有应用内聊天或工具型 Agent。
- 首版单 API 实例配一份 SQLite；评分 Worker 在同一部署中运行，持久任务可重启恢复。
- 不引入向量数据库、独立消息队列或模型编排平台；调用模型期间不持有数据库长事务。

## 2. monorepo 结构

确认采用 monorepo。建议 pnpm workspaces 管理 TS 包，Tauri 的 Rust 工程位于移动应用内。

```text
apps/
  server/
    src/
      modules/             # 账号、主题、计划、题目、作答、错题、归档
      grading/             # 模型适配、任务 Worker、得分项校验和汇总
      database/            # TypeORM 实体、迁移
  web/
    src/                   # 浏览器入口、Cookie 认证/CSRF、Web 平台适配
  mobile/
    src/                   # Android 入口、服务端选择、生命周期/凭据适配
    src-tauri/             # Tauri 2 Android、必要的薄 Rust 桥接
packages/
  contracts/               # 共享 DTO/题型/得分项协议，不含 ORM 实体或真实答案
  api-client/              # 请求、错误、分页与连接上下文，认证方式由平台注入
  learning-client/         # 共用 Vue 页面、路由、学习状态、UI 与样式体系
skills/
  drill-hub/               # 外部 Agent 使用说明，不含真实凭据
docs/
package.json               # 根为 private，统一脚本（后续创建）
pnpm-workspace.yaml        # apps/*、packages/*（后续创建）
pnpm-lock.yaml             # 统一 JS 依赖锁（安装后生成）
```

目录为设计，当前不创建空应用或伪造锁文件。脚手架时固定包管理器版本，内部包用 `workspace:*` 明确引用，包不对外发布。pnpm 工作区文件与协议已通过 Context7 和官方工作区文档核对。

依赖方向：

- web/mobile → learning-client → api-client/contracts。
- server → contracts；服务端 ORM、模型密钥、评分 Worker 不进入浏览器或 Android 包。
- learning-client 只调用注入的平台接口，不直接依赖原生安全存储。
- mobile 有独立启动入口，不能仅把 Web 生产地址塞进 WebView。
- 首版不用额外 monorepo 编排框架；HTTP 框架、构建和测试工具在脚手架阶段定。

## 3. 身份与权限

### Web

- 可撤销服务端会话，HttpOnly Cookie（HTTPS 下加 Secure），Web 写操作验证 CSRF；服务端允许所有来源的跨域访问。
- 密码只存强哈希；管理员安全初始化，无通用默认密码。

### Android

- 连接验证前不发送账号密码或历史凭据；验证后才展示该服务器的登录流程。
- 短期访问令牌放内存，轮换刷新凭据放平台保护的容器，不保留密码。
- 存储作用域绑定规范化地址 + instanceId + userId；退出清理本用户敏感草稿与会话。
- 凭据保护实现需真机验证，不允许用明文设置文件冒充安全持久登录。
- 账号停用、密码重置、凭据重用检测和撤销都使相应凭据失效。

### 外部 Agent

- 个人访问令牌只展示一次原文，服务端存摘要，绑定用户。
- scope：read、content:write、assessment:write、grading:request、grade:write、archive:write。grade:write 仅用于明确配置外部批改的题目，提交得分项等级而非任意分数。
- 不给自由写分、管理员模型配置、账号管理或永久删除权限；外部批改与内部模型按题目版本明确分工，不争抢同一题评分。
- 无论管理员角色还是 Agent 身份，均不能跳过资源所有权验证。

## 4. Android 自定义服务器

- 首次启动显示地址输入，允许 HTTP/HTTPS 地址与部署子路径，拒绝嵌入凭据、query、fragment。
- 拼接 API 路径要保留代理前缀；服务器连接页使用未认证请求调用 `/api/v1/server-info`。
- 验证固定服务标识、持久实例 ID、API 主版本和客户端兼容信息；不把响应中的任意 URL 自动当作新的登录地址。
- 标识检查只验证协议，不证明陌生服务器可信；确认页展示实际完整地址，提醒用户只连接可信服务器。
- 默认不跟随跨来源重定向登录，不给其他地址转发密码/令牌；使用 HTTPS 时证书错误不可跳过。
- 切换服务器中止在途请求和刷新计时器，清理前台状态，使用连接代号防止旧响应写回新状态。
- 地址变化或 instanceId 改变需重新确认/登录，即使名称相同也不复用凭据。
- 本地可保存最近连接信息；敏感数据不混入普通连接配置。
- Tauri 调用权限、网络策略须兼容用户自定义 HTTP/HTTPS 目标，但不因此开放任意原生功能或关闭 TLS 校验。
- 具体传输插件与实际 App 来源在 Android 技术验证阶段选择并核对文档；服务端允许所有来源的跨域请求。
- URL 连接是客户端到服务器；管理员可配置 HTTP/HTTPS 模型地址（含本机与私网地址），生产环境应通过网络边界限制服务端出站访问。

## 5. 内部模型评分服务

流程：提交/单题锁定事务写任务 → Worker 取任务 → 模型判断各项等级 → 校验 → 服务端汇总 → 追加评分记录 → 更新报告与错题。

- 默认模型只接收单题必要上下文，不提供数据库/API/Shell/联网工具。外部批改模式不创建模型任务，由 Agent 提交结构化得分项等级，同样服务端校验和算分。
- 得分项和答案快照是权威，模型输出不是权威总分。
- 持久任务包含状态、重试、租约、配置/提示词版本；网络调用在事务之外。
- 超时、限流、无效输出可有限重试，失败仍待评分，不记零分。
- 管理员在系统设置配置多个供应商及其模型，选择一个默认评分配置；供应商、地址、密钥、模型标识由服务端读取，不写死在应用中。
- 首版采用受支持协议的适配器注册表，界面展示可用类型；不承诺仅填写 URL 就能兼容任意未知协议，新增适配器时查对应当前文档。
- 保存配置后新评分任务绑定新的默认配置版本，不要求重新打包客户端；已入队任务不静默切换模型，缺配置/停用时进入可见阻塞，恢复需显式确认。
- 管理员修改配置或密钥不改变已结算成绩；每次评分记录实际使用配置/模型/提示词版本。
- 模型密钥存服务端受保护的密钥引用或加密字段，主密钥独立部署；客户端不保存或接收原文。
- 异步评分的去重、并发重评、失败恢复和预算要求见 05 文档。

## 6. 断网、计时与一致性

- serverTime/expiresAt 来自服务端；客户端倒计时只展示。
- 自动保存仅展示未保存、保存中和失败状态，不展示默认说明、保存成功提示或最后成功时间。
- 本地草稿按服务器实例、用户、会话隔离，不含标准答案、解析、模型密钥或 Agent 令牌。
- 本地草稿不是提交凭证；到期以服务端收到的答案结算，离线草稿不可补计分。
- 后台恢复重新查询会话，不能延时；多设备版本冲突显式提示。
- Worker 和到期结算在重启后恢复，读取/保存/提交路径也检查到期。
- 交卷冻结答案后即可返回待评分，不等待模型网络调用完成；任务完成与成绩最终完成是不同状态。

## 7. 安全与运维

- 业务查询及关联写入检查 owner_id，跨用户统一按不存在处理。
- 专用学习者 DTO 防止评分快照、标准答案或得分项提前泄露。
- 纯文本渲染，Agent 内容和用户答案不执行为脚本；评分提示词把答案视为不可信数据。
- 数据库不放静态目录；日志不写密钥、密码或完整敏感答案。
- 迁移管理表结构，生产不做无审查自动同步；SQLite 用持久卷。
- 模型费用、题目长度、并发、调用频率和重试有上限，单用户不能耗尽共享配额。
- 备份覆盖用户、题目、答案、评分任务和记录；加密配置恢复依赖独立保护的主密钥。
- 备份获得一致性快照并演练恢复；不直接复制运行中的主文件当完整策略。
- 服务与客户端版本兼容信息公开最小化，不公开内部拓扑或密钥。
