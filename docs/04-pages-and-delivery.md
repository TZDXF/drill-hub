# 04 · 页面、里程碑与验收

基线：v0.2。开发前计划，尚未初始化应用，不承诺固定工期。

Web 无需填写服务端地址，使用本站部署配置；Android 有独立启动流程。内置学习助手提供对话面板（桌面三栏/平板窄栏/手机全屏覆盖）与管理页；无模型自由对话页、用户改分页或 Webhook 空配置页。

主题详情页包含答题链接管理卡片（列举、状态与吊销）和永久删除危险区：删除前展示级联影响预览（各子资源计数），需确认后以 `expectedRevision` 提交，未终结作答会被拒绝。设置页提供“导出我的数据”（JSON 快照下载）。

## 2. Android 首次连接与切换

1. 无当前连接时进入 /connect，填写 HTTP/HTTPS 地址（含可选部署前缀）。
2. 规范化并验证传输连接、固定服务标识、实例和兼容版本，显示完整目标地址并要求确认。
3. 确认后进入 /login，才向该服务器发送账号密码。
4. 本地存在受保护会话时，在同地址和同实例验证后尝试恢复；失效返回登录。
5. 切换服务器前提醒未上传草稿和进行中考试不暂停；中止旧连接请求、刷新和前台状态。
6. 新服务器重新验证/登录，不转移旧凭据、答案或草稿。
7. 同地址响应了不同 instanceId，按新实例处理，不复用历史凭据。

连接错误单独区分：地址无效、超时、无网络、HTTPS 证书错误、不是本服务、API 不兼容。不能提供“忽略证书继续登录”。

## 3. 响应式、答题与评分反馈

- 桌面侧边导航；手机底部今日/主题/错题/我的，作答页隐藏普通导航。
- 手机单列，题号导航用弹层，选项整行可点；底部动作区适配安全区域和软键盘。
- 长文本可滚动，大字体不截断；列表在窄屏用卡片，不要求横向拖表。
- 阅读恢复位置；从学习计划打开内容并成功加载后自动完成来源阅读任务，不要求停留时长或滚动到底。直接浏览内容不更新计划任务，已完成任务不重复写入，归档计划不更新；自动完成失败时保留正文并提供重试。
- 自动保存不展示默认说明、保存成功提示或最后成功时间，仅展示保存中与失败状态，不展示等待保存提示或待保存数量；本地草稿不冒充服务端保存。
- 交卷确认包含未答/未保存数量，成功后即使待评分也明确说明答案已提交。
- 模型评分题展示等待/评分中/失败/已评分，不把未判显示为零分。
- 评分完成展示得分项满分、等级、得分、答案证据和简短反馈，不显示隐藏推理。
- 重评保留旧分并提示重评中；不提供改分按钮或允许用户直接指定等级。
- App 切后台/返回/重启不暂停考试，恢复后刷新服务端会话与评分状态。
- 空内容、断网、权限、已归档、停用账号分别呈现；纯文本不执行 HTML。
- 键盘导航、可见焦点、弹层焦点管理、非颜色单一反馈与可读错误提示纳入 Web 验收。

## 4. 里程碑

### M0 · monorepo 与关键技术验证

- 初始化 apps/server、apps/web、apps/mobile 和共享 contracts/api-client/learning-client。
- 锁定兼容版本与工作区管理，生成真实依赖锁文件；查询所选工具当前文档。
- 共用前端在 Web 和 Android 运行，Android 完成地址输入与服务验证。
- 验证原生凭据保护和自定义 HTTP/HTTPS 目标的网络权限；使用 HTTPS 时不关闭 TLS 校验。
- 实现模型协议适配边界，使用测试配置和合成得分项验证结构化判断与服务端计算，不把真实供应商或型号写死。

门槛：可复现基础构建、Android 连接验证、模型评分技术样例；iOS 不创建工程、不列入验收。

### M1 · 账号、隔离与模型配置

- 数据迁移、首位管理员初始化、账号启停/重置与密码修改。
- Web/Android 会话、CSRF、令牌权限/撤销、服务器实例信息。
- 系统设置的供应商/模型管理、密钥保护、连接测试、默认评分配置、基础审计。

门槛：A/B 无法跨用户读写；切换服务器不泄露凭据；模型密钥不进入客户端或日志。

### M2 · 学习与模型评分闭环

- 主题、计划、任务、内容、五种题型、题目/得分项版本、练习。
- Agent 批量生成及幂等；练习锁定、规则判分、持久模型队列、逐项结果；保留显式外部得分项批改。
- 规则填空与模型填空均实现；归档恢复从本阶段起覆盖核心资源。

门槛：Agent 创建内容和得分项，用户在 Web/Android 作答，内部模型评分，Agent 读取结果；无外部自由写分或用户人工改分。

### M3 · 考试、错题、重评与一致性

- 快照、服务端时限、交卷、超时结算与重启补偿。
- 报告、错题、重练、掌握状态；失败重试与有原因重评。
- 队列租约/去重、旧 Worker 写回保护、预算预留/并发限制。
- 模型评分匿名/合成样例回归，记录稳定性、延迟和成本。

门槛：断网/切后台/重启不破坏事实；无效模型输出不计分，模型失败不算零分。

### M4 · Android、部署与恢复验收

- Android 构建、签名配置、真机软键盘/安全区域/生命周期验证。
- 自定义服务器、实例变化、账号切换、凭据恢复与草稿隔离测试。
- 服务端部署、迁移、备份恢复、模型凭据恢复、API/客户端兼容。
- OpenAPI、外部 Agent Skill、管理员模型设置与用户使用说明。

门槛：Web 与 Android 分别记录真实结果，不以窄屏预览代替 Android 验收；不把商店上架视为默认完成。

## 5. 核心验收

### 隔离与权限

1. A 不能查询或引用 B 的资源，包括评分任务和归档。
2. 学习者与管理员会话不能提交分数或调用 Agent 管理接口；Agent 也没有自由写分端点。
3. 只读令牌不能写内容、评分、请求重评或归档；grade:write 不能覆盖模型/规则模式，撤销后的幂等重放失败。
4. 用户答案/题干中的脚本与伪工具指令不执行。
5. 系统设置仅管理员可写；模型配置测试不成为任意内网探测工具，配置响应和日志不泄密；普通用户与 Agent 不能读取密钥。

### 规则与模型评分

6. 五题型正确、错误、空白、非法输入；多选重复项、精确填空边界。
7. 模型简答按得分项给部分分；模型填空接受配置允许的同义表述，不跨空位取证据。
8. 未判不是零分/错题；全空直接零分且不调用模型。
9. 模型未知等级、漏项/重复项、任意总分、伪造证据导致拒绝计分与有限重试；外部得分项提交同样校验且不能抢占内部评分。
10. 模型超时/限流/预算不足/无配置保留可见待评分状态。
11. 重试和 Worker 重复返回只计一次分；旧 generation 不覆盖新重评。
12. 修改题目或得分项不影响已开始会话；重评固定原快照并追加原因。
13. 无效或失败重评不抹旧分；成功重评更新报告/错题但保留历史。
14. 权重除不尽、四舍五入、极小满分、满分/零分等级计算确定且不超分。
15. 模型回归含注入、否定、自相矛盾、同义、部分正确与冗长无关答案。

### Android 与计时

16. 首次无地址不能直接登录；未通过服务/兼容验证或传输安全检查不发送凭据。
17. 子路径保留正确，跨来源跳转不转发登录或令牌。
18. 换服务器/实例/用户不串凭据与草稿，旧请求结果不写入新连接。
19. 切后台、改手机时间、系统终止不延长考试。
20. 保存失败清晰提示；未收到的离线答案不补计分，多设备冲突不静默覆盖。
21. 到期和提交竞态只有一个有效结算，服务重启能恢复超时会话与评分任务。
22. 归档后不能新开始，但旧会话和评分仍可完成。

### 运维与交付

23. 空库安全初始化；无默认管理员密码，重复初始化不覆盖账号。
24. 一致性备份能恢复学习与评分事实，密钥恢复流程不泄密。
25. 生产包无真实密钥/标准答案数据，Android 真机结果如实记录。
26. iOS 不列为交付，也不生成占位“已支持”声明。

## 6. 后续与待确认

- 后续：回调投递、离线协议、原生深链、推送、资料导入；iOS 暂不考虑。内置学习助手已实现（docs/07-built-in-assistant.md）。
- 不再把选定供应商/型号作为编码前置问题：部署后在系统设置配置、测试、选为默认。开发需确定支持的协议适配器，上线前明确数据政策和预算。
- 工作区建议 pnpm；Android 签名、最低系统版本、发布渠道和备份保留期在对应阶段确定。
