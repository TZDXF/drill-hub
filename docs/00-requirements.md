# 00 · 首版需求与范围

日期：2026-10-17。基线：v0.2。已确认需求与本次细化建议分别标注。

## 1. 已确认的产品定位

- 多用户各自学习，服务器部署，支持手机浏览器；不做班级、教师或跨用户共享。
- 管理员创建账号，首版不开放注册；顶层容器叫“学习主题”。
- 用户主要在外部云端 Agent 中对话，在应用内学习与答题。
- 学习内容与题目主要由外部 Agent 创建，不做资料导入和解析，不强制人工审核。
- 增加内部评分模型，按简答题得分项判断，也支持填空题；用户不能手动改分。
- 供应商和模型在系统设置中配置，不写死具体供应商或型号；由管理员维护并选择默认评分模型。
- 应用内提供内置学习助手（基于 pi.dev 的 Pi，见 docs/07-built-in-assistant.md）；外部云端 Agent 对话仍是主要入口，助手不替代外部 Agent API。
- 移动端使用 Tauri 2，只考虑 Android，iOS 暂不在范围内。
- Android 先填写服务端地址，连接并验证服务器后再登录。
- 项目目录采用 monorepo 结构。
- 默认归档并可恢复；除非用户明确要求，否则不删除。

本次取代旧设计中的“首版不调用模型”“仅外部 Agent 批简答”“固定移动服务端地址”和“iOS 纳入目标”约定。

## 2. 学习能力

### 学习主题与计划

- 主题包含目标、计划、内容、题库、练习和考试。
- 计划采用阶段 → 任务结构，支持可选日期、预计用时和完成状态。
- 任务关联内容、练习集或试卷，也可为普通任务。
- 从学习计划打开阅读内容并成功加载后，自动完成对应阅读任务；普通任务由用户标记完成，练习/考试任务在提交后完成，不等待模型评分。
- 完成与掌握分开；未完成任务由 Agent 按需调整，不自动重新规划或解锁。

### 内容与题型

- 首版纯文本，保留换行；不执行 HTML，不做图片、音频、公式或富文本编辑器。
- 单选、多选、判断、填空、简答；支持解析和知识点标签。
- Agent 可批量创建并复用题目，同时提供答案、评分模式和必要的得分项。
- 学习者无标准答案编辑或人工改分入口。

### 练习与考试

- 练习单题提交并锁定后反馈；模型评分异步展示，不承诺即时完成。
- 考试支持时限、整体交卷、重考；交卷前不释放答案和得分项，不启动考试题目评分调用。
- 截止时间以服务端为准，不支持暂停、监考或复杂随机组卷。
- 报告区分已判得分、待评分分值、最终成绩和评分失败状态。
- 未评分题目不是零分或错题；未答题在交卷或超时结算时按零分处理。

### 错题与复习

- 已评分且未得满分的题目进入错题集，包括部分得分。
- 每次作答独立保存；汇总掌握状态为待复习、复习中、已掌握。
- 用户或 Agent 可调整掌握状态；再次答错自动回到待复习。
- 重练不覆盖历史；错题重练默认用当前题目版本，练习/考试用其配置中指定版本。

## 3. 评分规则（确认原则与细化建议）

| 题型 | 首版规则                                                                                  |
| ---- | ----------------------------------------------------------------------------------------- |
| 单选 | 选项 ID 与标准答案相同得满分                                                              |
| 多选 | 集合完全相同得满分；无部分分，重复选项是非法输入                                          |
| 判断 | 布尔值相同得满分                                                                          |
| 填空 | 默认 rule 精确匹配，可选 model_rubric；保留显式 external_rubric 外部得分项批改            |
| 简答 | 默认 model_rubric，内部模型逐项判断、服务端汇总；可显式选 external_rubric，均支持部分得分 |

### 规则填空

- 每空去除首尾空格后匹配该空的可接受答案；全部空正确才得满分。
- 默认不忽略大小写、内部空格，不做隐式语义判断。

### 模型评分

- 简答题与模型/外部批改填空必须有结构化得分项；不允许只给一句“自行打分”。
- 每项包含稳定 ID、判断标准、权重和允许的得分等级；填空项绑定空位 ID。
- 模型输出各项所选等级、答案证据和简短解释，不决定任意总分。
- 服务端按该次作答冻结的得分项与分值计算总分，并保存逐项结果。
- 模型填空按空位判断语义等价和关键条件，空白空位不得凭空获得分数。
- 未配置模型、调用超时或输出无效时保留待评分/失败状态，不静默记零分。
- 不因重试把模型评分自动降级为外部 Agent 自由打分或规则匹配。
- 外部 Agent 提供得分项、读取结果、请求模型重评；保留显式 external_rubric 模式，Agent 按相同得分项提交等级，由服务端算分，不能自由填总分。

### 共同约束

- 用户与管理员不能手动改分；管理员模型配置权不等于评分修改权。
- 分数按整数最小单位保存，对外用十进制字符串，不用浮点累加。
- 重评追加记录与原因，使用原作答、原题目和原得分项快照，不静默改变历史规则。
- 题目/得分项修改创建新版本，仅影响之后按新配置开始的作答。
- 首版不提供历史规则题的人工改分或重判。

## 4. 账号、Agent 与模型边界

- Agent 令牌绑定用户，可设置权限、期限，由本人复制和撤销；不能通过 ownerId 切换归属。
- Agent 管理接口可读取答案；学习者接口按提交时机释放，不能直接返回评分快照。
- 自学工具不声称能阻止用户借自己的 Agent 获取标准答案。
- 管理员负责账号管理和系统级供应商/模型设置；普通用户与外部 Agent 不得编辑系统配置或读取密钥。
- 模型调用只发生在服务端，最少发送题目、得分项和必要的用户答案，不发送用户身份或其他学习内容。
- 内部评分模型无业务工具权限；用户答案是待评价数据，不是模型可执行指令。
- 外部 Agent 按需读取学习结果；回调地址与主动触发后置。

## 5. 归档与删除

- 主题、计划、内容、题目、练习集和试卷可归档、恢复；阶段与任务随计划保留。
- 归档不清除作答、批改、模型评分任务、成绩、错题或关联。
- 归档父容器不批量改子资源字段；父容器归档期间不能开启新任务。
- 已开始的作答可完成，已提交的评分任务继续执行；账号停用的访问限制优先。
- 恢复父容器不自动恢复独立归档的子资源。
- 永久删除接口已实现：以主题为聚合根，显式删除需影响预览、expectedRevision 确认和审计；仅作答已终结的主题可删除。Agent 令牌需单独的 `topic:purge` scope（默认不授予）。

## 6. Android 连接流程

```text
首次启动 → 填写服务端地址 → 验证传输连接/服务标识/API 兼容性 → 确认服务器 → 登录 → 学习
```

- 允许重新填写或切换服务器；保留当前连接地址，登录页始终展示目标服务器。
- 允许 HTTP 或 HTTPS 部署，不将 HTTPS 作为远程连接硬性条件；HTTPS 正常校验证书，不提供忽略证书错误开关。HTTP 不加密传输，应只用于可信网络或由部署边界保护的场景。
- 服务端地址允许反向代理路径前缀；统一规范化，不接受地址中的账号密码、查询参数或片段。
- 切换前提示未上传草稿与进行中考试；切换不暂停原服务器考试。
- 会话、缓存和草稿按服务器地址、服务器实例、用户隔离；切换时不迁移凭据或自动上传旧草稿。
- 本地仅存连接配置、受保护的凭据和临时草稿，不实现第二份业务数据库。
- 无网络时明确提示；不支持离线开始考试，也不保证离线交卷。
- App 后台恢复重新读取服务器状态；页面分享保留，原生深链与推送后置。

## 7. 实现前尚需确定

- 无需预先指定供应商或型号；部署后在系统设置中添加并测试，再启用默认评分模型。开发阶段确定首批支持的协议适配器，上线前明确数据发送政策与成本限制。
- 得分项默认等级与权重细则：本稿建议未达成/部分达成/达成，必要时按项自定义等级。
- 工作区管理建议 pnpm workspaces，具体版本在脚手架阶段固定。
- Android 最低系统版本、应用名称/图标、签名身份、发布渠道与备份保留期。
- 回调、离线同步、桌面安装包均后置；iOS 暂不做工程规划与验收。内置学习助手首版已实现（docs/07），多设备推送与历史会话检索后置。
